# ⚔️ Info God of War

Um site desenvolvido para apresentar informações sobre a franquia **God of War**, destacando sua história, personagens e universo inspirado em diferentes mitologias.

O projeto foi desenvolvido como uma prática de **HTML5 e CSS3**, com foco na estruturação de páginas, organização de conteúdo, estilização e criação de uma interface simples e visualmente temática.

## 📌 Sobre o projeto

O **Info God of War** apresenta uma breve introdução à franquia e à trajetória de Kratos, abordando as diferentes fases da série, desde a mitologia grega até a mitologia nórdica.

A página também possui uma seção de contato, permitindo que o usuário preencha seus dados e envie uma mensagem, além de links para redes sociais.

## 🚀 Tecnologias utilizadas

* **HTML5** — estruturação da página
* **CSS3** — estilização e layout
* **Google Fonts** — utilização das fontes Bungee e Roboto
* **Flexbox** — organização dos elementos da página

## ✨ Funcionalidades

* Apresentação da franquia God of War
* Seção informativa sobre a história da série
* Menu de navegação interno
* Seção de contato
* Formulário para envio de mensagem
* Links para redes sociais
* Layout organizado utilizando Flexbox
* Estilização personalizada com CSS

## 🎨 Interface

A identidade visual utiliza tons de vermelho, branco e preto, buscando combinar com a temática do universo de God of War.

O projeto utiliza a fonte **Bungee** para títulos e **Roboto** para os textos, criando uma diferenciação visual entre títulos e conteúdo.
